# Family Violence in Victoria Data Visualisation Project

This project uses open data on family violence in Victoria to create an RShiny dashboard. The Data folder contains the required data files. 

The project proposal document outlines my plan for the project along with initial data collection and wrangling. The project report details my approach, motivations and how the final product meets the project aims.

The data_cleaning.R file cleans the main dataset, then app.R combines it with spatial data, and creates the dashboard. The json file allows the dashboard to be hosted on Posit Connect Cloud.
These files were created using RStudio, and therefore, if you wish to run them, I recommend doing so using RStudio. You will need the following packages installed:
tidyverse, dplyr, readr, sf, ggplot2, leaflet, scales, stringr, shiny, bslib
